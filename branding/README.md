## Inventario de Activos Vectoriales (`branding/assets/`)

- `isotipo-dark.svg` — Emblema cuadrado Obsidian & Champagne (uso digital principal, favicons, avatares)
- `isotipo-light.svg` — Emblema para fondos claros, documentos PDF y papelería corporativa
- `isotipo-mono.svg` — Versión monocromática para sellos, grabados, facturas y marcas de agua
- `logotipo-wordmark.svg` — Logotipo tipográfico puro `FIGURA` + descriptor `ARQUITECTURA FINANCIERA`
- `imagotipo-horizontal-dark.svg` — Imagotipo completo para headers web y presentaciones oscuras
- `imagotipo-horizontal-light.svg` — Imagotipo completo para propuestas PDF, contratos y documentos claros
- `imagotipo-vertical-dark.svg` — Imagotipo apilado para portadas, pitch decks y pantallas de carga
- `og-card.svg` — Tarjeta social OpenGraph (`1200×630`) para LinkedIn, WhatsApp y previews web
